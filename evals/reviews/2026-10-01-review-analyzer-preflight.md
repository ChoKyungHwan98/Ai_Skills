## Failure risk found in 4.1.0

The surface route required all eight layers to be changed in one pass and made specific effects, motion, taste questions, and a taste file sound routine. The entrypoint also directed a log count axis whenever values were skewed. Applied literally, these could create unrelated effects, modify a protected representation, or interrupt a user who explicitly delegated aesthetic judgment. The preset's concrete values were useful as examples but should not become a target for this application.

## 4.1.1 correction and verdict

The revised route inspects the whole surface and chooses changes from observed weaknesses. It makes project rules, accepted design definitions, and required mockups explicit. It keeps visual examples available without mandating them; taste records are optional. Chart-scale changes are separate from surface polish.

Packaging and instruction consistency: checked by repository validation. The preflight supports these narrow risk corrections.
